About Me

Hi, I'm Robel. I'm a designer, tinkerer, and student with a soft spot for bold black‑and‑white linework, spray‑paint texture, and websites that don't make people feel excluded.

This site started as a class assignment on accessibility and design. It's grown into a small gallery of the things I care about — and a place to practise building for the web the way I think it should be built: dark mode only, fully keyboard‑ navigable, and screen‑reader friendly from the ground up.

What I Do

  • Build accessible interfaces. Semantic HTML first, ARIA only where it's needed, and a visible focus ring on every single interactive element.
  • Design in the dark. Everything I ship is optimised for dark mode — not as a theme, but as the default.
  • Experiment with JavaScript. Small, dependency‑free scripts that add real interactivity without breaking the page for anyone.

What I Love

The other way to relax after a long day of debugging. Usually on headphones so I don't wake anyone.

How This Site Was Built

  • Hand‑written HTML, CSS, and vanilla JavaScript. No frameworks, no build tools.
  • A mobile nav toggle built with querySelector and addEventListener — no page reload, fully keyboard‑accessible.
  • An accessible contact form with inline error messages announced via role="alert", live character counting, and focus management on submit.
  • A live GitHub card powered by fetch() against the public GitHub REST API, with fallback handling if the request fails.
  • Reduced‑motion support, WCAG AA contrast, and a universal focus ring — because accessibility is not a feature, it's a baseline.
